# Koharia v1.0.0

这是定制并行版的首个正式版本。继续使用固定包名 `app.koharia.debug` 和既有固定签名，可直接覆盖安装此前的定制 Preview 版本。

## 本次重点修复

- 修复关闭“双击放大”并启用快速连续点击翻页后，卡顿时偶发仍触发图片放大的问题。
- 静态漫画页现在会在 SSIV 图片控件内部直接禁止双击缩放与双击 Quick Scale，而不是只依赖外围手势拦截。
- 动态图片使用的 PhotoView 在双击缩放关闭时也会直接消费双击事件。
- 双指捏合缩放继续保留，不受此次修复影响。

## 已包含的定制增强

- Komga 网络预加载：前向 1–100、后向 0–50。
- 漫画渲染预热支持固定与智能模式；智能模式以手动设置为绝对基线，只对较小图片额外加码。
- 基础渲染预热默认 5 / 1 / 5，并支持更大的手动范围。
- 快速连续点击翻页、底部隐藏快速跳页、阅读器状态覆盖层等定制阅读功能。
- 书架及阅读器中的“打开最新推送”等 Komga 定制功能。

## 下载

- ARM64 Android 平板/手机优先使用 `Koharia-v1.0.0-parallel-arm64-v8a.apk`。
- 不确定设备架构时可使用 `Koharia-v1.0.0-parallel.apk` 通用包。
- `SHA256SUMS.txt` 提供发布文件校验值。
